# v0.2：依据用户实际反馈迭代

用户明确反馈：首版视觉不满意、指令太多；要求对标 Magnet 实际界面，持续自动分屏（打开或关闭窗口时重排），独立图标。沿用轻量、本机、浅蓝、devflow 与 Claude 交叉审核约束。

## Must（6项）
1. 自动模式：默认开启意图，只有设备控制权限有效才工作；打开/关闭/最小化/还原窗口后重排。验证：真实时序Fixture自动开关窗口、暂停后新开不重排。
2. 范围与稳定性：只处理当前桌面上屏、普通、可缩放窗口，按显示器分别排列；不处理本应用或系统设置，忽略隐藏/最小化/其他Space/排除应用。保留已有窗口顺序，新窗口追加；鼠标按住时等待。验证：纯策略和真实AX；未实测Space/拖动另列。
3. 紧凑主界面：336×316，自动开关、即时整理、撤销并暂停；细分命令放高级菜单，快捷键默认关闭且独立设置页。验证：原生UI截图与点击。
4. 1–12窗布局：1窗最大化，2窗对半或竖向上下，3窗主辅/超宽三列，4–12窗网格填满最后一行；失败尝试恢复，不持续弹窗。验证：全范围几何/去重/边界/真实时序；兼容性限制明确保留。
5. 独立图标：imagegen新图标，ICNS打包，菜单栏单色符号；仍为零第三方运行时，包体目标<1MiB。验证：ICNS/Info.plist/签名、原生UI、实际字节。
6. 可恢复交付：旧版应用与源码checkpoint；新代码Claude审核，测试、签名、独立应用权限状态、zip和iCloud目标字节分别记录。验证：实际命令和哈希。

## Won't
后台桌面/Space搬运、系统全屏、游戏/固定窗口、关闭其他窗口管理器、修改系统平铺设置、自动授予权限、AI常驻/网络/账号/收费；不承诺所有软件或零缺陷。

## 引用与采用
实际查看开发者在Apple App Store发布的3.0.7截图：近白设置页、小布局图标、紧凑命令列表、侧栏。功能实现独立，未使用Magnet二进制。
Claude方案采用近白底、浅蓝强调、13/12点系统字体、菜单栏popover、分离快捷键页；用户后来明确选择持续自动，因此拒绝其“默认只一键、手动选择数量”的建议。窗口数量由程序自动判断。
