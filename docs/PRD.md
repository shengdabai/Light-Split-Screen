# 轻分屏 PRD
使用者和付款方：Tony 自用，免费本机工具；无收款。承诺：在辅助功能权限允许时调整可移动、可缩放的普通 macOS 窗口。成本：本机 Swift 编译、必要测试、一次 Claude 审核；运行不联网。

## Must（6 项）
1. 菜单栏与布局面板：半屏、上下、四角、三分屏、2/3、最大化、居中；保留菜单栏与 Dock。验收：几何单测 + 原生 UI。
2. 全局快捷键可更改，有占用反馈；可暂停。验收：编码/冲突检查 + 本机事件。
3. 拖到边缘出现预览，松开吸附；文本拖动和调整窗口大小不触发。验收：检测逻辑单测 + 真实窗口；受权限限制时明确未验。
4. 多显示器和窗口恢复：按最大交集选屏，跨屏保留比例；操作可撤销。验收：负坐标、上下排列、主屏顶坐标单测 + 实际可用屏幕。
5. 按显式选择的 2–4 个窗口应用双窗对照、开发三窗、等宽三窗或四窗；不读取窗口内容。验收：选择/数量/布局单测 + 本机窗口。
6. 轻量交付：原生 Swift/AppKit，零第三方运行时，安装包目标 <10 MiB，辅助功能引导、退出、排除应用与恢复说明。验收：构建/签名/包体、拒绝路径与文档。

## Should
调整窗口间距、拖边开关、排除应用；窗口最小尺寸不满足时报告实际结果而不是伪造成功。

## Won't
复制 Magnet 的品牌、图标或二进制；绕过授权；终止其他窗口管理器；自动登录启动；系统私有 API；控制全屏 Space、游戏/固定大小对话框；同步/云服务/AI 常驻；对所有本机软件兼容或零缺陷承诺。

日常方案是待验证假设：浏览器+资料/聊天双窗；编辑器占 2/3、终端与浏览器各 1/6 的开发三窗。窗口由用户选择，不扫描文件推断隐私习惯。首批用户来源 N/A（自用）。
