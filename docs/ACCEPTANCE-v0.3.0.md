## 已交付行为

用户反馈旧版重启后窗口跳动。旧实现会恢复 continuousAuto=true，窗口陆续恢复时持续重排；关闭自动模式后还可能启用 DragSnap。新版每次启动强制关闭，覆盖旧的开启偏好；登录项仅启动菜单栏入口。用户已自行选择系统登录项，本轮未代改其他软件。

Control＋S（⌃S）松开时切换一次，长按不重复切换。自动开关独立于可选手动快捷键，暂停后也能开启。关闭会取消排队整理、窗口监听与计时器，同时停用拖边吸附，保留窗口当前位置。重复开启不会重启已有协调器或清除失败预算。

只有 autoToggle 的精确 Control＋S 允许单主要修饰键；其他单 Control、裸键、Command＋S 均拒绝。当前用户未保存自定义快捷键，实际使用默认 Control＋S。应用运行时会全局接管这个组合，可能影响其他软件对 Control＋S 的使用；用户已获说明并选择该组合。系统或其他拦截器造成的冲突不能全部由注册结果检测。
