# 轻分屏 v0.3.0

轻量 macOS 菜单栏窗口管理器。使用原生 Swift/AppKit，浅蓝色界面、独立三窗图标。没有账号、网络请求或第三方运行时。运行入口：`~/Applications/轻分屏.app`。

## 日常使用

点击菜单栏的三窗图标，打开 336×316 点的小面板。每次启动默认关闭自动分屏，登录启动仅显示菜单栏入口。按 **⌃S（Control＋S）** 开启自动分屏，再按一次关闭；可在「快捷键」设置中修改。按键松开时切换一次，长按不会连续开关。主动开启后，打开、关闭、最小化或恢复普通窗口会自动整理当前桌面上的窗口。不同显示器分别排列，保留菜单栏和 Dock。

- 1 个窗口铺满可用区域；2 个窗口平分；3 个窗口采用主窗加两个副窗；4 个及以上使用网格。竖屏、超宽屏会调整方向。每屏最多 12 个窗口。
- 新窗口加入布局，已有窗口尽量保持顺序。鼠标按下时延后整理，避免打断拖动。
- 关闭自动分屏时停止窗口监听、轮询、待执行的整理和拖边吸附，保留当前窗口位置。重新打开应用也不会恢复上次的开启状态。
- 「立即整理」重新整理当前桌面。「撤销并暂停」恢复上一批位置，并关闭持续自动。
- 手动分屏、跨屏移动和自选 2–4 个窗口排列放在「手动」菜单。手动操作会暂停自动模式，避免两者争抢。
- 设置分「通用」和「快捷键」。自动分屏开关 ⌃S 始终注册，会接管全局 Control＋S，可能影响其他软件原有的同一组合。手动布局快捷键默认关闭。若开关快捷键被其他软件独占注册，设置会显示失败，可改用其他组合或面板开关。系统快捷键和事件拦截工具仍可能产生无法检测的冲突。拖边吸附已停用，避免关闭时仍自动移动窗口。
- 在设置中选择要忽略的应用；可调窗口间距 0–32 点。

「自动」按窗口数量和显示器尺寸采用固定规则，不分析窗口正文，也不学习个人习惯。布局规则仍需日常使用验证。

## 首次授权

应用设置必须显示实际权限已生效，系统开关开启本身不能证明应用已获授权。

在「系统设置 → 隐私与安全性 → 辅助功能」添加本应用。当前系统可能把该面板显示为「设备控制和数据访问」。如果旧版本条目已开启，但应用仍提示等待权限，请先退出应用，移除旧条目，再添加 `~/Applications/轻分屏.app`，开启后重新打开应用。

本机版本采用 ad-hoc 签名，未经 Apple 公证。重新编译会改变签名，macOS 可能要求重新授权。应用只检查实际权限；不会修改 TCC 数据库、重置或自行授予权限。未授权时不会调整窗口。

## 限制与恢复

只调整当前桌面上可移动、可缩放的普通软件窗口。系统全屏、最小化、浮动面板、画中画、固定尺寸对话框和部分自绘窗口不参与排列。同一应用的多个窗口若位置完全重合而无法唯一匹配，会跳过并提示。

同一个可调整窗口集合和目标布局失败最多尝试 3 次。临时面板和跳过写入的空计划不会重新激活它；新增普通窗口、改变布局目标或手动「立即整理」可重新尝试。应用最小尺寸超过目标区域时，会尝试恢复整批位置并报告失败；恢复也可能被目标应用拒绝。一个应用拒绝调整可能导致这批其他窗口一并回滚。若经常发生，请在设置中忽略该应用。

自动发现主要使用系统窗口通知，另每 3 秒核对一次屏上窗口成员。不会在每次轮询时反复写入尺寸。AX 调用在主线程执行，响应慢的应用仍可能造成短暂卡顿。Stage Manager、跨 Space、系统原生平铺及所有第三方应用的组合尚未完成实际兼容性验证。

最多保存 30 批撤销、80 个窗口的原始位置，以及每个显示器最近 80 个窗口的顺序；只存内存，退出后清空。设置只保存开关、快捷键、间距和忽略列表。不会采集或上传窗口正文、键盘输入和截图。本机已按用户要求加入系统「登录时打开」。可在「系统设置 → 通用 → 登录项与扩展」关闭。

## 源码与构建

Apple Silicon；编译目标 macOS 13+，当前测试系统为 macOS 27.0.1 / arm64。需要 Command Line Tools 自带 Swift；无需 npm、Node、Electron 或 Xcode 项目。

```sh
./scripts/test.sh
./scripts/integration.sh
./scripts/auto-integration.sh
./scripts/control-integration.sh /tmp/qingfenping-control-test-new
./scripts/build.sh "$HOME/Applications/轻分屏.app"
```

编译前先退出当前应用。两个集成脚本只操作自己创建的专用 Fixture 窗口，结束后关闭测试进程。测试宿主的辅助功能权限与独立应用权限分开验收。不要给 `--fixture-pid` 传入普通应用 PID；它只接受专用测试程序，格式错误会退出。
